FAQs

Prototype page — content for review

A starting set of questions about using the prototype.

How do I find a cell line?

Open Search & Filter, enter a search term or select filter options, then choose Show Detailed Results.

How do I select diseases or variants?

Use the arrows to expand categories and choose the options beneath them. All Diseases selects the available disease entries.

Can I return to my results after opening a record?

Use Back to detailed results. The prototype retains your search and page selections within the same browser session.

What do the download icons do?

The share icon copies the page link. JSON downloads the sample record. PDF opens the browser print dialog, where you can choose Save as PDF.

Are the prototype counts the full Registry totals?

No. The results currently use repeated sample records to demonstrate filtering and pagination.
