# Body system disorder artwork

Source: ASR_System_Illustration_A3.pdf supplied by Charles, 30 October 2026.

The ten WebP assets correspond to pages 1–10: default, nervous, visual, auditory, musculoskeletal, connective, urinary, cardiovascular, blood/immune, digestive. Artwork and connector geometry are rendered from the supplied PDF. Text operators were omitted while retaining graphics state, so the website can render accessible linked names and live counts instead of the placeholder 34. The page-4 duplicate Auditory label is not repeated.

Disease membership uses the existing Registry disease tree via data/body-systems.js. Visual combines visual-system and orbital-region categories; Blood and Immune combines blood and immune categories. Auditory uses the otorhinolaryngologic category. Missing categories (currently urinary and blood) contribute no diseases; no matches are invented. Each matching source record counts once per system even if it matches several child diseases. Different systems can overlap.

Counts and body-system listing links use the same unexpanded Registry snapshot. The source illustration's 34 Cell Lines text is a placeholder and is not used as a count.

Desktop labels support hover, focus, keyboard activation and direct links. Phones show system names and counts as a compact linked list.
